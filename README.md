# Retail Sales Analytics Dashboard

## Overview
This project is an end-to-end retail sales analysis built using Python, SQL, and Power BI.

The goal is to analyze business performance and generate insights on revenue, products, and customer behavior through an interactive dashboard.

---

## Tools & Technologies
- Python (Pandas)
- SQL (MySQL)
- Power BI
- DAX
- Excel

---

## Workflow
- Collected dataset from Kaggle
- Cleaned and transformed data using Python
- Performed analysis using SQL queries
- Built interactive dashboard in Power BI

---

## Dashboard Highlights

### Executive Overview
Tracks key KPIs and overall sales performance across time, location, and payment methods.

### Product Performance
Analyzes product categories, pricing segments, and order status.

### Customer Insights
Explores customer demographics, regional distribution, and behavior patterns.

---

## Key Insights
- Revenue is heavily concentrated in Maharashtra (MH), contributing significantly more than other states, indicating potential geographic dependency and growth opportunity in underperforming regions

- Digital payments dominate with over 80% of transactions, highlighting strong customer preference for online channels and reduced reliance on offline methods

- Customers aged 26–45 drive the majority of revenue, suggesting that middle-aged segments are the most valuable and should be the primary target for marketing and product strategies---
